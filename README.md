# Board Game Store

A modern web application built with **React** and **TypeScript** for browsing and purchasing board games.

## Features

- **Catalog**: Browse games with real-time pricing and availability.
- **Cart**: Add items and manage your shopping cart effortlessly.
- **Orders**: Place orders and track your purchase history.

## Getting Started

### Prerequisites

- Node.js installed on your machine.
- A local backend service running on port `8080`.

### Installation

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the application:
    ```bash
    npm start
    ```
    The app will run at [http://localhost:3000](http://localhost:3000).
